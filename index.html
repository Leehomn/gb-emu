TECH · 技术亮点

四个模块，一台主机

不用现成模拟器框架，核心逻辑逐个模块手写。

CPU

LR35902 处理器

SM83（类 Z80）主指令集 + CB 前缀位操作，取指 / 译码 / 执行循环逐条手写， Z / N / H / C 标志位逐一对齐——Blargg 指令考卷 75/75 全过。

INTERRUPT

中断系统

VBlank / LCD / Timer / Serial / Joypad 五个向量统一调度， IME + IE/IF 精确控制——手柄按键、屏幕刷新的及时响应都由它保证。

IE @ $FFFF · IF @ $FF0F
VBLANK · LCD · TIMER · SERIAL · JOYPAD
中断向量 $40 – $60 · IME 开关

TIMER

定时器

DIV + TIMA/TMA/TAC：按 TAC 分频累加，溢出回装并请求中断—— 游戏里的每一秒，都从这里来。

DIV @ $FF04 · TIMA @ $FF05
TMA @ $FF06 · TAC @ $FF07
TAC 四档时钟 → 溢出 → TIMA 中断

PPU

图像处理器

背景与精灵两层扫描线渲染，含 SCX/SCY 滚动、图块映射、 调色板与 OAM DMA，点亮 160×144—— 经典 DMG 四阶绿，正是本站配色来源。

JOURNEY · 学习路线

从 CHIP-8 到第一块砖

从 CHIP-8 入门机一路打通到 Game Boy 的像素世界——每一站都真实走过。

  1. STAGE 01

    CHIP-8：第一个模拟器

    1977 年设计的入门虚拟机：35 条指令、64×32 单色屏。先用 Python 写通「取指 — 译码 — 执行」循环，跑通第一个模拟器。

  2. STAGE 02

    学 Rust

    换一门系统级语言练手：所有权与借用检查逼你想清楚每一块内存的归属，match 把 opcode 映射成指令枚举——写模拟器内核的趁手工具。

  3. STAGE 03

    Game Boy CPU

    LR35902（SM83）指令集逐条实现：A–L 八个 8 位寄存器、栈指针、程序计数器与内存总线一一对应，内核逐步成形。

  4. STAGE 04

    Blargg 考卷：75/75

    社区公认的指令级考卷，从第一题做到 75/75 全部通过——核心逻辑拿到「合格证」，才敢往下接屏幕。

  5. STAGE 05

    PPU 显像：第一块砖落下

    每帧 70,224 个时钟周期、每秒 59.7 帧的节奏，逐行画满 160×144——屏幕亮起那一刻，2048 的数字方块落在自己写的机器上。
